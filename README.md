# CHIKV Kenya 2024-2026 — Nextstrain build

Phylodynamic analysis of the 2024-2026 Chikungunya virus (CHIKV) outbreak in northeastern
and coastal Kenya (Mutai et al., in revision).

## Current build
- **149 focal (study) genomes** + **512 context genomes** = 661 sequences aligned;
  **658 tips** in the final time-resolved tree (3 pruned as molecular-clock outliers by
  `augur refine --clock-filter-iqd 2`: the alignment ref plus 2 context genomes
- Inferred clock rate: see `phylogenetic/results/tree/inferred_clock_rate.txt`.
- The Garissa/ONT genomes were called at a 20x minimum consensus depth (`sensitivity_analyses/ont_consensus_threshold_sweep/`)
- All focal genome accessions are listed here (`accessions/genbank_seqids.txt`).

## Reproducing this build
**Primary method = Snakemake:**
```
snakemake --cores 8
```
run from the repo root. This regenerates the full pipeline from `context_seqs.fasta` +
`final_focal_seqs.fasta` all the way to `auspice/chikv-kenya-2024-2026.json` (18 rules: context
filtering, focal filtering, combine, align, mask, tree, an automated `treetime clock` rate
derivation, refine, traits, ancestral, translate, export). Verified via `snakemake -n`
(dry-run) to resolve cleanly end-to-end from this repo's own files with no external paths.

**Fallback — plain bash:** `bash ingest/results/build.sh` runs the same augur commands
without Snakemake, in case Snakemake isn't available. No internet access is required
either way once `ecsa_seqs.fasta`/`metadata.tsv` exist (or are regenerated by the Snakefile).
