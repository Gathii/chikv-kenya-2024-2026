# CHIKV Kenya 2024-2026 - Nextstrain build

This repository accompanies the Phylodynamic analysis of the 2024-2026 Chikungunya virus (CHIKV) outbreak in northeastern
and coastal Kenya (Mutai et al., in revision).

Starting December 2024, febrile illness with joint pain was reported in Garissa County, followed a month later by similar 
cases along Kenya's coast, continuing through mid-2026. Plasma samples from Garissa (n=32) and coastal surveillance sites 
(n=1,632) were screened for CHIKV by qPCR. Positive samples were sequenced (Nanopore PromethION and Illumina NextSeq 2000, 
with VirCapSeq-VERT enrichment), assembled, and analyzed phylogenetically using Nextstrain.

Key findings:
- CHIKV positivity: 40.6% (Garissa) and 30% (coast)
- All genomes (149) recovered were East/Central/South African (ECSA) genotype–Indian Ocean Lineage and clustered with recent Indian strains. 
- Three independent introductions into Kenya since 2016 (2016, 2018, 2024)
- The 2024–2026 outbreak stems from a single introduction (MRCA dated ~Nov 2022), indicating cryptic circulation before detection, 
followed by parallel spread into northern and coastal sub-lineages
- Notable mutations found (E1-K211E, E2-I211T, nsP3-R524*); the Ae. albopictus-adaptive E1-A226V mutation was not detected
- Major surveillance gap: only 5% of confirmed cases were clinically suspected as chikungunya (most were misclassified as dengue,
   URTI, or undifferentiated fever)



## Current build
- **149 focal (study) genomes** + **512 context genomes** = 661 sequences aligned;
  **658 tips** in the final time-resolved tree (3 pruned as molecular-clock outliers by
  `augur refine --clock-filter-iqd 2`: the alignment ref plus 2 context genomes
- Inferred clock rate: see `phylogenetic/results/tree/inferred_clock_rate.txt`.
- The Garissa/ONT genomes were called at a 20x minimum consensus depth (`sensitivity_analyses/ont_consensus_threshold_sweep/`)
- All focal genome accessions are listed here (`accessions/genbank_seqids.txt`).

## Reproducing this build
**Primary method = Snakemake:**
```
snakemake --cores 8
```
run from the repo root. This regenerates the full pipeline from `context_seqs.fasta` +
`final_focal_seqs.fasta` all the way to `auspice/ecsa_iol_chikv.json`.

**Fallback:** `bash ingest/results/build.sh` runs the same augur commands without Snakemake, 
in case Snakemake isn't available. No internet access is required either way once 
`ecsa_seqs.fasta`/`metadata.tsv` exist (or are regenerated by the Snakefile).
